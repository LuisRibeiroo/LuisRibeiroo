## How I work

- **AI inside the process, not just the editor.** Spec first: PRD, plan, then implementation by agents, guided by per-repo rules and reusable [agent skills](https://github.com/LuisRibeiroo/skills).
- **AI-assisted testing.** Agents draft unit and widget tests, probe edge cases and review diffs. I keep the final call on what ships.
- **Releases from the terminal.** App Store Connect and Google Play uploads run from CLIs, so a release is a command, not a checklist of console clicks.
- **Tools when something slows the team down.** If a workflow hurts, I build the fix and open-source it.
